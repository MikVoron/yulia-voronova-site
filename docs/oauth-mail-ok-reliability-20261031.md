# Доступность Mail и Одноклассников

На рабочей странице воспроизведён скриншот с двумя обычными кнопками: SDK и клиентские файлы вернулись с HTTP 200, но `/auth/oauth/vk/config` ответил HTTP 429. Для подготовки виджета действовал лимит 10 запросов за 15 минут с IP, который могли исчерпать обычные перезагрузки и открытые вкладки.

Лимит подготовки изменён на 30 запросов в минуту. Ограничения callback входа сохранены. Дополнительно добавлены собственные кнопки Mail и Одноклассников в запасной интерфейс: они используют существующий redirect VK ID с allowlist `mail_ru` / `ok_ru`, тем же приватным PKCE и обработчиком аккаунтов. При работающем One Tap остаются значки штатного виджета. Схема `provider` и `prompt=login` соответствует [официальному коду VK ID SDK](https://github.com/VKCOM/vkid-web-sdk/blob/master/src/auth/auth.ts).

Проверки: 43 серверных теста (включая настоящий плагин rate-limit: 30 успешных запросов и отказ следующего), 21 браузерный сценарий, 7 проверок стабильности геометрии страницы, 6 изолированных Linux-сценариев установщика. В браузере отдельно воспроизведён HTTP 429 конфигурации и проверены оба запасных перехода. Настоящий вход через внешние аккаунты в этих тестах не выполнялся.

Установщик меняет один API-маршрут и три клиентских файла, делает свежий checkpoint и закрытую копию этих файлов, проверяет API до установки кнопок и поддерживает откат своего выпуска без восстановления БД. Рабочее окружение, nginx и правила подписки не меняются. На момент этого коммита исправление ещё не установлено.
