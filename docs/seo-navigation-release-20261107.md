## Изменение

Главная получает актуальные категории, восемь популярных рецептов с реальными оценками и ссылки на используемые ингредиенты до выполнения JavaScript. Общий каталог также получает ссылки на ингредиенты. Данные выбираются заново при запросе; неопубликованные рецепты исключены. Полные ингредиенты и шаги платных рецептов в карточки не включаются.

Карточки категорий являются ссылками с `href`, сохраняют перенос выбранных фильтров при обычном переходе и допускают стандартное поведение модифицированного клика. Серверные карточки сохраняются при сбое клиентского API. Главная доступна без JavaScript через ограниченный `noscript`-стиль.

SQL заменяет обратный слеш на обычный в `recipes.photo` и `steps[1].photo` только для `side-bulgur`. Перед изменением проверяются идентификатор, имя и оба исходных пути; повторное применение допустимо. Остальные поля, включая публикацию, доступ и тексты, сравниваются после обновления; меняется также техническое время обновления.

Улучшение исходного HTML уменьшает зависимость навигации от JavaScript. Оно не является доказанным устранением причины исключения страниц из Google и не гарантирует индексирование.

## Пакет и установка

Пакет собирается `scripts/build-seo-navigation-release.cjs` из изолированной рабочей копии и четырёх снимков production. К существующим файлам применяются только рассмотренные изменения; посторонние live-изменения сохраняются. Пакет содержит точные исходные и новые SHA-256.

Файлы назначения:

- `/var/www/smartplate-api/src/home-seo.js` — новый модуль;
- `/var/www/smartplate-api/src/routes/content.js`;
- `/var/www/smartplate-platform/index-page.js`;
- `/var/www/smartplate-platform/index.html`;
- `/etc/nginx/sites-available/plate.voronova.online` — только маршруты `/` и `/index.html` к серверному HTML.

Перед изменениями установщик проверяет хеши, UID/GID процесса 997, владельца PM2, запросы навигации к БД в read-only транзакциях и создаёт полный checkpoint. SQL проходит dry-run с откатом. Отдельная резервная копия содержит пять файлов и состояние рецепта; откат рецепта защищён от поздних правок.

API перезапускается с существующим root-owned PM2. Готовность проверяется с повторными попытками перед включением нового маршрута nginx. Ошибка запускает откат только файлов этого релиза и его SQL-правки. Зависимости, настройки PM2, авторизация и CSP не меняются.

После установки проверяются исходный HTML обоих адресов главной, каталог, API фото «Булгура», Recipe JSON-LD, публичный хеш index-page.js, sitemap и здоровье API. Маркер успеха: `SEO_NAVIGATION_RELEASE_OK`.

После команды владельца дополнительно проверить публичный браузер и сохранить фактические результаты установки. Только затем отмечать релиз установленным.

## Контроль индексации

Пять адресов: `/`, `/category.html?cat=breakfasts`, `/recipe.html?id=grechotto`, `/recipe.html?id=toast-chickpea-olives`, `/recipe.html?id=wholegrain-wheat-pancakes`.

Для каждого сопоставлять последнее автоматическое сканирование, Google canonical, статус URL и показы после нового обхода/обновления отчёта. HTTP 200, зелёный live-тест и маркер установки не считать доказательством индексирования. Полный технический аудит повторять только при новых изменениях или симптомах.
