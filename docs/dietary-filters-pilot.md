# Пилот диетических фильтров

## Безопасность

- Базовая точка возврата: `dietary-filters-baseline-2026-06-04` (`0edd1ced`).
- Существующие рецепты не скрываются, пока `dietary_verified` не равен `TRUE`.
- `server/migrate-dietary-pilot-recipes.sql` добавляет только пилотную разметку и
  оставляет `dietary_verified = FALSE`.
- Для экстренного отключения фильтрации:

```sql
UPDATE recipes SET dietary_verified = FALSE;
```

## Поверхности выдачи

Фильтрацию получают через общий список `RECIPES`:

- главная страница и карточки категорий;
- поиск;
- каталог и отдельные категории;
- подборки по основному ингредиенту;
- избранные рецепты;
- автоматические дополнения к рецепту;
- прямой переход на скрытый рецепт.

Отдельно фильтруются серверные указатели:

- `/content/categories`;
- `/content/news`;
- `/content/seasonal`.

История тарелки и уже сохранённые записи не скрываются: это личный исторический
снимок пользователя, а не новая рекомендация.

## Пилотные рецепты

| Рецепт | Назначение | Разметка |
|---|---|---|
| `hummus` | нейтральный контроль | без признаков |
| `celeriac-apple-salad` | молоко без замены | рецепт `milk`, йогурт `milk` |
| `pasta-tuna-yogurt` | молоко с заменой | рецепт `fish,milk,gluten`; йогурт `milk`; соус из кешью `nuts` |

## Ожидаемые сценарии после проверки и включения `dietary_verified`

| Ограничения пользователя | `hummus` | `celeriac-apple-salad` | `pasta-tuna-yogurt` |
|---|---|---|---|
| Без молока, замены разрешены | виден | скрыт | виден |
| Без молока, замены запрещены | виден | скрыт | скрыт |
| Без молока + без орехов | виден | скрыт | скрыт |
| Без рыбы | виден | виден | скрыт |
| Без глютена | виден | виден | скрыт |

Перед включением `dietary_verified` нужно вручную подтвердить состав рецепта,
признаки каждого конфликтующего ингредиента и совместимость каждой замены.
