# Гайд: ручной ввод рецепта в админке

Шпаргалка для заполнения формы рецепта в админке платформы. Охватывает:
- основные поля (время, порции, вес, КБЖУ);
- единицы измерения в ингредиентах и шагах;
- панели «Добавки» (4 категории: белки / жиры / углеводы / клетчатка);
- автодобавки (auto_addons) — какие добавки появляются в карточке сами, без ручного ввода.

Смотреть вместе с: [`docs/ai-recipe-input-contract.md`](ai-recipe-input-contract.md) (контракт AI-парсинга текстового рецепта).

---

## 1. Основные поля рецепта

| Поле в админке | Формат | Пример | Комментарий |
|---|---|---|---|
| **ID** | латиница, цифры, `-` | `borscht-red-beans` | slug, уникальный. Используется в URL и ссылках. |
| **Название** | строка | «Борщ с красной фасолью» | |
| **Emoji** | 1 эмодзи | 🥣 | По умолчанию 🍴. |
| **Категории** | чекбоксы | ☑ mains | Минимум одна. Первая в списке — основная. |
| **Время, мин** | целое число | `45` | Только минуты, без «ч». 1 час = 60. |
| **Сложность** | `easy` / `medium` / `hard` | medium | |
| **Порций** | целое | `10` | Сколько порций получается из рецепта целиком. |
| **Порция, г** | целое, без единиц | `400` | Вес **одной** готовой порции. Главные КБЖУ считаются на эту порцию. |
| **Ккал / Б / Ж / У / Клетч.** | число | `123` / `6` / `2` / `23` / `6` | На одну порцию (см. выше). Целые или с десятичной точкой. |
| **Теги** | через запятую | `без глютена, растительное, без сои` | |
| **Фото** | относительный путь | `images/recipes/borscht-red-beans/borsch-cover.webp` | Только `.webp`. Путь относительно корня platform. |
| **is_free** | чекбокс | ☐ | `on` = triala-доступ, `off` = Pro. |
| **is_published** | чекбокс | ☑ | Неопубликованные не видны пользователям. |

## 2. Ингредиенты

Формат — **одна строка = один ингредиент**. Количество пишется **внутри названия** свободным текстом (парсер не расщепляет).

```
<название> — <количество> | <замена (опционально)>
```

### Единицы измерения (пиши как тебе удобно, парсер не проверяет)

| Вид | Примеры |
|---|---|
| Граммы | `350 г`, `800 г`, `25 г` |
| Штуки | `1 шт`, `2 средние`, `3 зубчика`, `1 крупный`, `2 стебля` |
| Объём | `3 л`, `250 мл`, `1 ст. л.`, `2 ст. л.`, `1 ч. л.`, `1/2 ч. л.` |
| По вкусу | `по вкусу` |
| Запасные варианты в скобках | `350 г (отварная или консервированная)` |

### Замены (правая часть после `|`)

Альтернативный продукт, если основной недоступен. Пишется одной строкой:

```
Томатная паста — 2 ст. л. | Томаты в собственном соку — 200 г
Укроп — 25 г | Петрушка
```

На карточке появится кнопка «чем заменить?».

### Примеры

```
Вода — 3 л
Картофель — 2 средние
Белокочанная капуста — 800 г
Красная фасоль — 350 г (отварная или консервированная)
Томатная паста — 2 ст. л. | Томаты в собственном соку — 200 г
Укроп — 25 г | Петрушка
Соль — по вкусу
```

### Кросс-ссылки на другие рецепты

Внутри названия/замены можно дать ссылку на рецепт в формате `[текст](recipeId)`:

```
Соус из кешью — 1 ст. л. | [Йогурт](yogurt-sauce) — 1 ст. л.
```

При рендере это превратится в кликабельную ссылку на рецепт.

## 3. Шаги приготовления

Каждый шаг — отдельная строка.

### Простой шаг (без фото)

```
Лук мелко нарежьте, сельдерей и картофель нарежьте кубиками.
В кипящую воду добавьте картофель, капусту и лавровый лист.
```

### Шаг с фото

Пиши как JSON-объект на одной строке (редактор допускает смешивать простые и объектные шаги):

```json
{"text": "В кипящую воду добавьте...", "photo": "images/recipes/borscht-red-beans/borsch-2.webp"}
```

### Шаг с несколькими фото

`photo` может быть **массивом** строк:

```json
{"text": "Добавьте чеснок и лимонный сок.", "photo": ["images/recipes/borscht-red-beans/borsch-10.1.webp", "images/recipes/borscht-red-beans/borsch-10.2.webp"]}
```

Фронт отрендерит как карусель: одно фото обычного размера, переключение стрелками.

### Контракт `step.photo`

| Значение | Поведение |
|---|---|
| `"path/to.webp"` | одно фото |
| `["p1.webp", "p2.webp"]` | N фото галереей |
| `true` | плейсхолдер-заглушка |
| `null`, `""`, отсутствует | блок фото не рендерится |

**Не пиши несколько фото через запятую в одной строке** — парсер не разобьёт, фото сломается.
В recipe-editor вставляй несколько URL в поле фото шага по одному URL на строку — редактор сохранит это как JSON-массив. В SQL/API указывай именно JSON-массив.

### Что НЕ включать в шаги

- `-start.webp` — подкладывается автоматически перед разделом «Приготовление».
- `-final.webp` — подкладывается автоматически в финальный шаг «Наслаждайтесь».

Фронт сам вычисляет их пути из cover-фото.

## 4. Панели «Добавки» (add-ons)

4 текстовых панели в админке: **Белки / Жиры / Углеводы / Клетчатка**. Каждая добавка — **одна строка**:

```
<имя> | <количество> | <ккал> | <белки> | <жиры> | <углеводы> | <клетчатка> [| @<recipeId>]
```

### Поля

| Поле | Формат | Пример |
|---|---|---|
| `имя` | текст | `Белое мясо`, `Тофу`, `Цельнозерновой хлеб` |
| `количество` | **свободный текст** (отдельное поле `amount`) | `50 г`, `100 г`, `1 ломтик`, `1 шт`, `1 ст. л.`, `1 порция` |
| `ккал / Б / Ж / У / клетч.` | число | пересчитано под это количество, **не на 100 г** |
| `@recipeId` | опционально, последняя колонка | `@hummus`, `@oregano-croutons` |

### Поле «количество» — что туда писать

Это **отдельное поле** (не часть имени). На карточке отображается через точку-разделитель: `Тофу · 100 г`.

| Тип | Примеры |
|---|---|
| Граммы | `50 г`, `100 г`, `35 г` |
| Штуки | `1 шт`, `2 шт`, `1 ломтик`, `1 зубчик` |
| Объём | `1 ст. л.`, `1 ч. л.`, `250 мл`, `0.5 л` |
| Порции | `1 порция`, `0.5 порции` |

**Важно:** нутриенты (ккал/Б/Ж/У/клетч.) должны быть **пересчитаны** под указанное количество. Если пишешь `35 г`, то и ккал/Б/Ж/У — именно для этих 35 г.

### `@recipeId` — ссылка на рецепт

Опциональная последняя колонка. Если указана — на карточке появится кликабельная ссылка «→ Открыть рецепт».

Для внешних продуктов (мясо, тофу без рецепта) — просто не добавляй.

### Примеры строк (скопировать в textarea)

```
Белое мясо | 50 г | 80 | 16 | 1 | 0 | 0
Тофу | 100 г | 70 | 10 | 4 | 1 | 0
Соевые бобы эдамаме | 100 г | 109 | 12 | 5 | 3 | 5
Хумус | 40 г | 75 | 3 | 3 | 10 | 3 | @hummus
Цельнозерновой хлеб | 1 ломтик | 70 | 3 | 1 | 15 | 3
```

### Legacy-формат (без `amount`)

Парсер поддерживает старый формат (6 полей через `|`, без `amount`):
```
<имя> | <ккал> | <белки> | <жиры> | <углеводы> | <клетчатка>
```
Но новые записи **лучше** делать с `amount` — на карточке видно граммовку.

## 5. Автодобавки (auto_addons) — появляются в карточке сами

Механизм: ряду рецептов платформа добавляет в сайдбар **общие** добавки автоматически, без ручного ввода.

### Текущие правила

| Что к чему | В какой слот | Источник |
|---|---|---|
| К **котлетам** (`cutlets`) | Клетчатка | Все рецепты из `salads` (салаты) |
| К **котлетам** (`cutlets`) | Углеводы | Все рецепты из `sides` (гарниры) |
| К **гарнирам** (`sides`) | Клетчатка | Все рецепты из `salads` (салаты) |
| К **гарнирам** (`sides`) | Белок | Все рецепты из `cutlets` (котлеты) |
| К **супам** (`is_soup=true`) | Углеводы | Статический «Цельнозерновой хлеб — 1 ломтик» + рецепт `oregano-croutons` |

Правила котлет и гарниров живут на уровне **категории** (`categories.auto_addons`). Правило супов живёт в рендере карточки через бизнес-флаг рецепта `is_soup=true`: супы остаются в `mains`, но получают хлеб и сухарики автоматически.

### Как это видно в админке

- **Модалка категории** (admin.html → «Категории» → «редактировать») — дропдауны «из какой категории тянуть» для каждого слота. Можно изменить/добавить правило.
- **Модалка рецепта** (recipe-editor.html) — секция «Автодобавки» с дропдаунами (пока поддерживает только `fromCategory`, статические `items` — passthrough из БД, не редактируются в UI).

### Дедупликация

При рендере сайдбара карточки:
1. Сначала идут **ручные** добавки из `add_protein/add_fat/add_carbs/add_fiber`.
2. Потом **авто**, но дубли пропускаются:
   - по `recipeId` (если ручной add-on ссылается на тот же рецепт);
   - по имени (case-insensitive).

Поэтому если на супе вручную добавить «Цельнозерновой хлеб» — авто не задвоит.

### Формат rule (для слота в `auto_addons`)

```json
{
  "carbs": {
    "fromCategory": "breads",
    "items": [
      {"name": "Цельнозерновой хлеб", "amount": "1 ломтик", "kcal": 70, "protein": 3, "fat": 1, "carbs": 15, "fiber": 3}
    ]
  }
}
```

- `fromCategory` — подтягивает все опубликованные рецепты из категории.
- `items` — статические продукты (не-рецепты). Используется, когда нужно добавить продукт, у которого нет отдельного рецепта (например, «цельнозерновой хлеб» как продукт).
- Оба поля опциональны, можно указать любое одно или оба.

### Когда появится новый суп

Рецепт супа не попадает в категорию «супы» автоматически (её нет — супы лежат в `mains`). Чтобы новый суп получил авто-добавку хлеба/сухариков, поставь ему флаг `is_soup=true` в recipe-editor или SQL:

```sql
UPDATE recipes
SET is_soup = true
WHERE id = 'new-soup-id';
```

Не нужно копировать `recipes.auto_addons` у старых супов: текущее правило супов работает через `is_soup`, а не через per-recipe `auto_addons`.

## 6. Цитата / заметка

- **Цитата** — одно поле, короткий личный комментарий автора (1-3 предложения). Отображается блоком в шапке рецепта.
- **Заметка** (`note`) — опциональное поле, показывается ниже цитаты.

### Кросс-ссылки

Внутри цитаты/заметки работает синтаксис `[текст](recipeId)` — ссылка на другой рецепт.

---

## 7. Видео

3 отдельных поля: `yt_video`, `vk_video`, `dzen_video`. Пустые = прочерк.

Формат — **полный URL**, не embed-код:
- YouTube: `https://youtu.be/XXXX` или `https://www.youtube.com/watch?v=XXXX`
- VK: `https://vkvideo.ru/video-XXX_YYY` или `https://vk.com/video-XXX_YYY`
- Дзен: `https://dzen.ru/video/watch/XXXXX`

Фронт сам конвертит в embed при рендере.

## 8. Быстрая проверка после сохранения

1. Открой карточку рецепта в обычном режиме (`recipe.html?id=...`), проверь:
   - Граммовка в ингредиентах написана корректно (`— 2 ст. л.`, `— 350 г`).
   - В сайдбаре добавок у каждой позиции видна граммовка (`Тофу · 100 г`), а не только имя.
   - Мультифото шаги показывают галерею, а не один битый URL со запятой.
   - На котлетах — есть салаты (Клетчатка) и гарниры (Углеводы).
   - На супах — есть «Цельнозерновой хлеб» и сухарики в Углеводах.
2. Клик по add-on меняет КБЖУ в верхней балансной полоске и не ломает подсчёт.
3. Unpublished рецепт не виден пользователю без админских прав.
