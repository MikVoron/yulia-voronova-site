# ТЗ для Claude Design: новая обёртка email-писем «Умной тарелки»

## Задача

Нужно переделать общую брендированную обёртку всех email-писем SmartPlate под текущий дизайн платформы «Умная тарелка».

Обёртка используется для:

- сервисных писем пользователям: вход, регистрация, подписка, платежи, ответы на обращения;
- новостной рассылки и анонсов рецептов;
- внутренних уведомлений администратору.

Тексты самих писем уже редактируются отдельно. Нужен дизайн повторяемых элементов:

1. внешний фон письма;
2. шапка бренда;
3. контейнер основного текста;
4. основная CTA-кнопка;
5. сервисный блок помощи;
6. нижний брендовый подвал;
7. ссылка отписки для новостной рассылки.

## Где это будет внедряться

Основной файл:

- `server/src/email.js`

Функции:

- `wrap(body, unsubscribeToken, showSupportFooter)` — общая обёртка;
- `wrapService(body)` — сервисные письма с блоком помощи;
- `btn(text, url)` — основная кнопка.

Все стили должны быть пригодны для вставки в HTML-строки как inline-стили.

## Текущий дизайн платформы

Ориентироваться на SmartPlate, а не на корневой публичный сайт.

Основные источники:

- `platform/style-v4.css`
- `platform/index.html`
- `platform/cabinet.html`

Текущая визуальная система:

- редакционный стиль, близкий к кулинарному журналу;
- белый фон и тёплый дополнительный фон;
- чёрная авторская полоса;
- крупный бренд с serif-заголовком;
- тонкие границы вместо тяжёлых теней;
- чёрный текст и оранжево-красный акцент.

Токены:

| Назначение | Значение |
|---|---|
| Белый фон | `#ffffff` |
| Тёплый фон | `#faf8f5` |
| Граница | `#e5e5e5` |
| Акцент | `#e8400a` |
| Тёмный акцент | `#c73208` |
| Основной текст | `#111111` |
| Вторичный текст | `#444444` |
| Третичный текст | `#777777` |
| Чёрная полоса | `#161616` |
| Sans-шрифт | `Montserrat`, system-ui, sans-serif |
| Serif-шрифт | `Playfair Display`, Georgia, serif |

Текущая шапка платформы:

- верхняя чёрная полоса: `ЮЛИЯ ВОРОНОВА · НУТРИЦИОЛОГ`;
- ниже: `ПЕРСОНАЛЬНЫЙ ПОМОЩНИК В ПИТАНИИ`;
- бренд: `Умная тарелка`, слово `тарелка` выделено цветом `#e8400a`.

## Ограничения email-дизайна

Нужно проектировать именно email, а не веб-страницу.

- Максимальная ширина письма: `560–600px`.
- Верстка должна быть устойчивой в Gmail, Mail.ru, Яндекс Почте, Outlook и мобильных клиентах.
- Использовать table-based layout для сложных горизонтальных блоков.
- Все критичные стили должны быть inline.
- Не полагаться на CSS-переменные, flex, grid, hover, sticky, JavaScript, SVG или внешние CSS-файлы.
- Веб-шрифты могут не загрузиться: обязательно предусмотреть хорошие fallback-шрифты.
- Основной текст должен оставаться читаемым при отключённых изображениях.
- Кнопка должна быть заметной без hover-состояния и иметь крупную область нажатия.
- Избегать слишком светлого серого текста и слишком мелкого кегля.
- Не использовать декоративные элементы, которые требуют сложной адаптивности.
- Фото или логотип не должны быть единственным способом идентифицировать бренд.

## Обязательные элементы

### Шапка

Должны присутствовать:

- `Юлия Воронова`;
- `Нутрициолог`;
- `Умная тарелка`;
- подпись `Персональный помощник в питании`.

Можно использовать или не использовать фото Юлии. Если используется фото:

- текущий URL: `https://voronova.online/images/YV-small.webp`;
- фото не должно делать письмо похожим на старый дизайн;
- предусмотреть корректное отображение без изображения.

### Основной контент

Внутрь обёртки будет подставляться переменная `body`.

Обёртка не должна задавать конкретный заголовок письма или конкретный текст.

### CTA-кнопка

Внутрь кнопки подставляются переменные `text` и `url`.

Кнопка должна подходить для разных подписей:

- `Открыть Умную тарелку`;
- `Оформить подписку`;
- `Продлить подписку`;
- `Посмотреть рецепт`;
- `Открыть личный кабинет`;
- `Проверить оплату в админке`.

### Сервисный блок помощи

Показывается только в пользовательских сервисных письмах.

Точный текст:

> Нужна помощь? Напишите на hello@voronova.online или воспользуйтесь формой в разделе «Связь» личного кабинета.

Ссылки:

- email: `mailto:hello@voronova.online`;
- раздел «Связь»: `https://plate.voronova.online/cabinet.html?tab=feedback`.

### Нижний подвал

Должен содержать:

- бренд или название платформы;
- ссылку на `https://plate.voronova.online/`;
- аккуратное место для ссылки `Отписаться от рассылки`, которая появляется только в новостных письмах.

Не показывать текст `voronova.online`, если ссылка фактически ведёт на `plate.voronova.online`.

## Три направления

### Вариант A. Editorial Masthead

Самый близкий к текущей шапке SmartPlate. Рекомендуемый вариант.

Идея: письмо выглядит как компактная страница кулинарного журнала.

Wireframe:

```text
┌────────────────────────────────────────────┐
│  ЮЛИЯ ВОРОНОВА  ·  НУТРИЦИОЛОГ            │  чёрная полоса
├────────────────────────────────────────────┤
│       ── ПЕРСОНАЛЬНЫЙ ПОМОЩНИК ──         │
│              Умная тарелка                 │  serif, «тарелка» оранжевая
├────────────────────────────────────────────┤
│                                            │
│  {body}                                    │
│                                            │
│        [ Основная кнопка ]                 │
│                                            │
├────────────────────────────────────────────┤
│  Нужна помощь? ...                         │  тёплый фон
├────────────────────────────────────────────┤
│  Открыть Умную тарелку · Отписаться        │
└────────────────────────────────────────────┘
```

Характер:

- строгий;
- редакционный;
- хорошо узнаваемый;
- без фото;
- тонкие линии и большое количество воздуха;
- CTA может быть чёрной с оранжевым акцентом или полностью оранжевой.

Плюсы:

- максимально соответствует текущей платформе;
- не зависит от загрузки изображения;
- подходит и пользователям, и внутренним уведомлениям.

Риск:

- нужно не сделать шапку слишком высокой для коротких писем с кодом входа.

### Вариант B. Personal Note

Идея: письмо выглядит как личное сообщение от Юлии, но сохраняет текущую редакционную систему.

Wireframe:

```text
┌────────────────────────────────────────────┐
│  [фото]  Юлия Воронова                    │
│          Нутрициолог                      │
│          Умная тарелка                    │
├────────────────────────────────────────────┤
│  ПЕРСОНАЛЬНЫЙ ПОМОЩНИК В ПИТАНИИ          │
│                                            │
│  {body}                                    │
│                                            │
│  [ Основная кнопка ]                       │
├────────────────────────────────────────────┤
│  Нужна помощь? ...                         │
├────────────────────────────────────────────┤
│  Умная тарелка · Перейти на платформу      │
└────────────────────────────────────────────┘
```

Характер:

- более тёплый и персональный;
- подходит письмам с подписью `Ваша Юля`;
- фото небольшое, не декоративное;
- бренд менее журнальный, чем в варианте A.

Плюсы:

- усиливает доверие;
- хорошо подходит для welcome, окончания триала и новостей.

Риски:

- внутренние уведомления могут выглядеть излишне личными;
- без фото композиция должна оставаться аккуратной.

### Вариант C. Minimal Utility

Идея: максимально чистая сервисная обёртка, где бренд присутствует, но не отвлекает от действия.

Wireframe:

```text
┌────────────────────────────────────────────┐
│  Умная тарелка                             │
│  ПЕРСОНАЛЬНЫЙ ПОМОЩНИК В ПИТАНИИ          │
│  ───────────────────────────────────────   │
│                                            │
│  {body}                                    │
│                                            │
│  [ Основная кнопка ]                       │
│                                            │
│  ───────────────────────────────────────   │
│  Нужна помощь? ...                         │
│  Юлия Воронова · Нутрициолог               │
└────────────────────────────────────────────┘
```

Характер:

- компактный;
- утилитарный;
- быстрый для чтения;
- особенно хорош для кода входа, оплаты и уведомлений администратору.

Плюсы:

- короткие письма не выглядят перегруженными;
- проще всего поддерживать в разных почтовых клиентах.

Риск:

- может быть недостаточно выразительным для новостной рассылки и анонсов рецептов.

## Что нужно вернуть

Подготовить для каждого из трёх вариантов:

1. Краткое визуальное обоснование.
2. Цвета, размеры, отступы и типографику.
3. Desktop и mobile preview.
4. HTML-фрагмент общей обёртки с плейсхолдером `{{BODY}}`.
5. HTML-фрагмент CTA-кнопки с плейсхолдерами `{{TEXT}}` и `{{URL}}`.
6. HTML-фрагмент сервисного блока помощи.
7. HTML-фрагмент нижнего подвала с опциональной ссылкой `{{UNSUBSCRIBE_LINK}}`.
8. Комментарий о совместимости с Gmail, Mail.ru, Яндекс Почтой и Outlook.
9. Рекомендацию, какой вариант выбрать как основной.

## Критерии приёмки

- Визуально письмо узнаваемо как часть текущей платформы SmartPlate.
- Оно не выглядит как старая карточка с круглыми углами и фото в рамке.
- Шапка не занимает слишком много места в письме с кодом входа.
- Текст остаётся главным, CTA хорошо заметен.
- Обёртка подходит и сервисным письмам, и новостям, и внутренним уведомлениям.
- Дизайн устойчив без картинок и без загрузки веб-шрифтов.
- Все важные стили можно перенести в inline-атрибуты.
- На мобильном экране письмо не требует горизонтальной прокрутки.
- Ссылка отписки видна, но не конкурирует с основным CTA.

## Рекомендация для выбора

Начать с **варианта A — Editorial Masthead**. Он лучше всего повторяет текущую шапку платформы и может стать единым визуальным стандартом для всех писем.

Если вариант A окажется слишком тяжёлым для коротких сервисных писем, рассмотреть гибрид:

- шапка из варианта A;
- компактные отступы и подвал из варианта C;
- фото Юлии не использовать.
