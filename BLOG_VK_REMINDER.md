# Как добавить VK-кнопку к посту в блоге

1. Открой файл `data/blog-vk-links.json`.
2. Добавь в него строку по шаблону:

```json
"НОМЕР_ПОСТА": "ССЫЛКА_НА_VK"
```

Пример:

```json
"320": "https://vk.com/im/channels/-232523704?cmid=211"
```

Важно:

- слева должен быть именно номер Telegram-поста;
- между строками в JSON нужны запятые;
- если записи для поста нет, VK-кнопка на `blog.html` не появится.

3. Из корня репозитория запусти:

```powershell
node scripts/update-blog.js
```

4. После этого генератор обновит `blog.html`, и у поста появится кнопка VK.
