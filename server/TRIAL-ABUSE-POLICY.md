# Политика наблюдения за злоупотреблением триалом

Дата решения: 2026-06-27.

## Что применяется сейчас

- browser fingerprint принимается только как SHA-256: ровно 64 hex-символа;
- malformed fingerprint отклоняется до использования login code и пишется в
  `audit_log` как `trial_fingerprint_invalid`;
- отсутствие fingerprint пока не блокирует регистрацию, но email-регистрация
  журналируется как `trial_fingerprint_missing`;
- повторный валидный fingerprint по-прежнему не получает второй триал;
- IP используется только как сигнал наблюдения. Автоматического отказа в
  триале только из-за общего IP больше нет.

Это важно для семей, офисов, общественного Wi-Fi и мобильных операторов с
CGNAT: один публичный адрес не равен одному человеку.

## Допустимое количество аккаунтов с одной сети

Порог считается по регистрациям с одним IP, но сам по себе не блокирует:

| Окно | Норма | Наблюдение | Сигнал |
|---|---:|---:|---:|
| 24 часа | до 5 | 6–10 | 11+ |
| 7 дней | до 10 | 11–20 | 21+ |
| 90 дней | до 20 | 21–30 | 31+ |

`watch` и `alert` пишутся в `audit_log`; `alert` дополнительно отправляется в
Telegram не чаще одного раза в 6 часов для одного IP. В сигнале есть только
счётчики, способ регистрации и IP — автоматической блокировки нет.

## Период наблюдения

Собирать данные минимум 30 дней. Перед блокировками проверить:

- сколько `watch` / `alert` пришлось на реальные семьи, офисы и мобильные сети;
- долю регистраций без fingerprint;
- повторные fingerprints и последующие оплаты;
- частоту сигналов по одному ASN/провайдеру, не только по IP.

Решение о step-up принимать по сочетанию сигналов, например: новый fingerprint
+ высокий network count + отсутствие последующей оплаты. Один IP недостаточен.

## Варианты более сильной идентификации

### 1. Подтверждённый телефон

Плюсы: понятен пользователю, один номер можно ограничить одним триалом.
Минусы: стоимость SMS, защита номера как персональных данных, виртуальные номера
и дополнительное трение на регистрации.

Практичный вариант: запрашивать телефон не у всех, а только при `alert` или при
регистрации без fingerprint после накопления статистики.

### 2. Подтверждённый платёжный метод

Плюсы: сильнее связывает триал с человеком, хорошо защищает дорогой продукт.
Минусы: выше трение, нужна поддержка PSP и прозрачное объяснение временной
авторизации/возврата.

Реализовывать только через токенизацию платёжного провайдера. Не хранить номер
карты, CVC или полный платёжный реквизит в SmartPlate.

### Рекомендация

Сейчас оставить наблюдение. Если за 30 дней подтвердится существенный обход,
добавить step-up с подтверждённым телефоном для сочетания риск-сигналов. Метод
оплаты рассматривать позже, если триал станет дорогим или появится полноценный
онлайн-эквайринг.
